# 词纱

在 DSH 左侧栏里管理你的英语考试词：自动收集你真实遇到的词，按记忆强度安排复习，并把已掌握的词重新拿出来抽查。

## 功能

- **考试包**：内置小学、KET、PET、高考、四级、六级、考研；可同时启用多个包并设一个主包。新增考试只需加数据包，不需要改插件。
- **自动收集（默认关闭）**：开启后，Host 只在本机读取桌面会话里的 user message，按已启用考试包识别候选词：
  - 问词/短句直接收进词本，当天到期；
  - 长文只进候选池，等你点头；
  - 每天有上限，3 天没评级自动移出复习队列，不堆债。
- **对话词纱**：总开关开启时，浏览器把 agent 回复里的考试词替换成英文，并保留原文；鼠标悬停或键盘聚焦显示中文、词性、音标和掌握状态。对话顶栏有本对话专用临时开关，切到其他对话使用总开关；临时开关允许只在本对话开启显示，自动收集/复习/红点仍由总开关控制，override 只保存在当前页面内存（刷新重置）。代码块、链接、命令、路径不替换，关闭开关即恢复原文。
- **错误热力**：按错误率、练习次数和 lapses 分色；颜色只做“注意力分层”，严重错误用暖色、学习进度用冷色、已掌握用绿色、未收录用灰色；单词本顶部有颜色图例，悬浮卡和 aria-label 同时给出文字状态，不单靠颜色表达。亮/暗主题分别取色，正文对比度均 ≥ 4.5:1。
- **顶栏状态**：今日复习量、待复习量、最近考试日期，所有对话可见。
- **每日复习**：轻量 10+2、标准 25+5、冲刺 50+10，或自定义。到期词按主包核心、顽固词、到期时间、词频排序。
- **间隔**：长期默认最多 60 天；考前可把上限改成 14 天。答错当轮重问一次，再错明天。
- **检索与生产**：英→中选择题；中→英给首字母/长度提示，严格匹配目标词。答错当轮重问一次，再错明天。
- **掌握与抽查**：掌握要求至少两个不同日期的检索正确、其中至少一次生产型、SRS 达到「熟」且非顽固。抽查把已掌握/顽固词重新拿出来考，答错降级。
- **红点**：有到期/新词时图标右上角出现；完成一次真实检索后当天熄灭；没有待办时每天首次打开亮一次。可关闭。

## 颜色系统

颜色按“注意力预算”排，不把所有词都染成高饱和：

| 档 | 含义 | 亮色 | 暗色 | 视觉权重 |
|---|---|---|---|---:|
| 高频错 | 错率 ≥ 50% / 近期连错 ≥ 3 / 最近仍错且 lapses ≥ 3 / 顽固 | `#b42318` | `#ff7b72` | 600 |
| 易错 | 错率 ≥ 30% / 近期连错 ≥ 2 / 最近仍错且 lapses ≥ 2 | `#b9430c` | `#ffa657` | 600 |
| 需巩固 | 错率 ≥ 15% / 有近期错误 / 曾用 hard 重试 | `#8a5d00` | `#d4a72c` | 500 |
| 已收录 | 已进词本、未练习 | `#0f766e` | `#2bb3a3` | 500 |
| 稳定 | 有练习、非顽固 | `#1d4ed8` | `#79c0ff` | 500 |
| 已掌握 | 检索/生产/间隔均达标 | `#137333` | `#6bc46d` | 500 |
| 新词 | 尚未收录 | `#5f6b7a` | `#9aa4b2` | 400 |

- 暖色/红色只留给真正的错误，避免“满屏都在报警”；蓝/绿/青用于进度，降低与错误词的竞争。
- 亮暗主题通过 `light-dark()` 分别取色；上表所有文字色对其主题背景的对比度都 ≥ 4.5:1。
- 不只靠色相：错误档同时加粗，悬浮卡和 `aria-label` 有“高频错/易错/已收录”等文字，红绿色觉异常用户也能读状态。
- 图例顺序按“错误 → 待巩固 → 已收录 → 稳定 → 已掌握 → 新词”，和实际优先级一致。
- 参考：[W3C WCAG 2.1 对比度](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum.html)；[Elliot (2015) 颜色心理功能综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC4383146/)；[Aalto “Colour in human-centred interface design” 系统综述](https://aaltodoc.aalto.fi/handle/123456789/136539)；[Ant Design 状态色/开关源码](https://github.com/ant-design/ant-design/blob/master/components/switch/style/index.ts)；B 站 [UI 配色思路](https://www.bilibili.com/video/av595161216)、[色彩心理学](https://www.bilibili.com/video/av114024754709942)、[7 个 UI 色彩误区](https://www.bilibili.com/video/av115248602289547)。

## 安装

本地开发版通过 DSH 的 **Plugins > Add plugin** 添加本目录，然后**完整退出 DSH 再打开**。公开发布后会提供 npm 安装命令，但发布需要维护者逐次批准。

## 首次运行

1. 选择考试包（预选小学，可改；至少一个），并设主包。
2. 选择每日档位（默认标准 25+5）或自定义。
3. 决定是否开启自动收集（默认关闭）。
4. 打开「启用词纱」开关；开启后同时启用词本功能和对话词纱。
5. 可选：添加考试日期（可多个，默认不显示倒计时）。

## 数据与隐私

- 词本、收件箱、备份：`~/.dsh/plugins-data/dsh-word-veil/`。
- 自动收集默认关闭；只在本机处理；只存词和短上下文片段，不存整条消息；可关闭、清空、导出。
- 无遥测、无外网。Host 路由只允许 loopback 请求。

## 限制

- v1 不做整段翻译，也不做任意中文词的悬停；对话词纱只替换词包映射命中的词。
- 划词收藏、悬停任意词——计划 v1.1。
- 对话词纱是浏览器显示层替换，不改会话里保存的原中文；它依赖 DSH Chat 的 assistant-step DOM，Chat 大改版时需要适配。复制选中文本时，词纱区域会带出英文；需要原始中文时先关闭词纱，或从会话记录复制。
- 词纱目前作用于已结束的 assistant 回复；流式生成中的文本暂不替换，结束后统一生效。
- v1 不做 agent 工具；v1.1 加只读的到期/词本查询。
- 考试包成员来自大纲词头清单，释义/音标来自 ECDICT；核心层不是官方真题核心。
- 自动收集无法真正判断「你不会的词」，只能用问词/短句/词频做代理；需要按自己的使用调阈值。
